# 图匹配

项目创建于 2025 年 10 月 10 日。

#### [2025-10-10]

设计表示 ACC 与 Func 匹配关系的数据结构。

考虑到优化整个 ACC 与 Func 匹配估计是个 NP 难的问题，计划首先尝试先匹配变量再对应 ACC 与 Func 的近似算法。

#### [2025-10-11]

初步写了 DFS 的匈牙利算法，参考了：

https://blog.csdn.net/KYJL888/article/details/106055942

但还没有检验。

初步实现了文件输入和算法执行并打印结果（仅包括匹配数），但还没有仔细调试。

用贾辉给的测试数据（保存为“BiGraph1.txt”，名称化简后为“BiGraph1-s.txt”），共 13 对 ACC 与 Func，两边的变量各 9 个；跑完匈牙利算法后得到最大匹配为 6，此时有 4 对 ACC 与 Func 匹配了。但是用人工手算的方法得到，这个问题的最优解应该是 5 对 ACC 与 Func。所以在这个程序上的近似效率为 80%。

#### [2025-10-13]

用贾辉给的新测试数据（保存为“BiGraph2.txt”），共 736 对 ACC 与 Func，两边的变量分别为 26 和 38 个；跑完匈牙利算法后得到的最大匹配为 23，此时仅有 3 对 ACC 与 Func 匹配？？！
